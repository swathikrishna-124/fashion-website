# Fashion Website

## About the Project
A fashion website built using HTML and CSS to showcase clothing collections, stylish outfits, and fashion offers through a simple and attractive interface.

## Features
- Clothing collections for different styles
- Men's and women's fashion sections
- Casual, formal, and denim outfit displays
- Fashion offers section
- Product images and navigation links

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
